# **Wypożyczalnia sprzętu narciarskiego – Stos technologiczny**

### 

| Technologia | Po co | Uzasadnienie |
| :---: | :---: | :---: |
| **C\# / .NET 8 \+ WPF** | Aplikacja desktopowa | Standard na uczelni, dużo tutoriali, jedno środowisko dla całej grupy (Visual Studio) |
| **MVVM** | Architektura UI | Oddziela widok od logiki |
| **SQLite** | Baza danych | Zero instalacji, baza to jeden plik, każdy z grupy odpala projekt od razu |
| **Entity Framework Core (Sqlite)** | Dostęp do bazy | Klasy zamiast ręcznego SQL, mniej kodu i mniej błędów |
